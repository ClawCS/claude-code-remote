# Rental document fonts

Unmodified Noto Sans regular and bold TrueType fonts, embedded into rental PDFs to retain Unicode names. SIL Open Font License 1.1 is included in `OFL.txt`; the fonts are not sold separately.

Source: [notofonts/noto-fonts](https://github.com/notofonts/noto-fonts/tree/ffebf8c1ee449e544955a7e813c54f9b73848eac/hinted/ttf/NotoSans), pinned upstream commit `ffebf8c1ee449e544955a7e813c54f9b73848eac`.

SHA-256:

- `NotoSans-Regular.ttf`: `b85c38ecea8a7cfb39c24e395a4007474fa5a4fc864f6ee33309eb4948d232d5`
- `NotoSans-Bold.ttf`: `c976e4b1b99edc88775377fcc21692ca4bfa46b6d6ca6522bfda505b28ff9d6a`
- `OFL.txt`: `0dab92d0544f7b233403f14b84a663bdbfa746982eda629e7f4f9ffe1b036feb`

Unsupported glyphs produce an explicit error rather than being silently omitted. The fonts are document assets, not photographs or replacement website imagery.
